# 🏗️ 3D Game Engine  

**3D Game Engine** is a custom-built **C++ engine** designed for **real-time 3D rendering, physics, and world creation**.  
The main feature of this engine is its **3D Editor**, allowing users to build and manipulate game worlds.  
Several projects have been developed using this engine, including a **Bowling game, a Doom clone, a Descent remake, and a 3D World Editor**.  


## 🛠️ Engine Features  

✅ **Custom 3D Renderer** → OpenGL + GLEW-based rendering.  
✅ **Model & Asset Loading** → Assimp for importing various 3D formats.  
✅ **JSON Scene Serialization** → Uses RapidJSON for saving/loading game worlds.  
✅ **Custom UI** → ImGui for in-editor controls.  
✅ **Text Rendering** → SDL2 TTF for UI and debugging.

## 🎮 Projects Built With the Engine


### 🏗️ **3D World Editor**
- **Create and edit 3D environments** using a custom-built editor.
- **Import 3D models** with **Assimp** and adjust materials/textures.  
- **Scene Outliner, Object Manipulation, and Real-Time Preview**.  
- **Uses ImGui for UI customization**.

### 🕹️ Controls  

- **Move Camera** → `WASD`
- **Rotate View** → `Right Mouse Button + Mouse Movement`
- **Delete Object** → `Delete Key`
- **Save Scene** → `Ctrl + S`  
- **Save As Scene** → `Ctrl + Shift + S`  
- **Load Scene** → `Ctrl + L`
